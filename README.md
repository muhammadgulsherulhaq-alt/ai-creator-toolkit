# AI Creator Toolkit

Black + sharp red AI content tool for creators.

## Current MVP
- YouTube/Shorts/TikTok title generator
- Hook generator
- Thumbnail text ideas
- Mobile-first UI

## Local/static preview
Open `index.html` to preview the design.

## AI backend
The `/api/generate.js` file is a Vercel serverless function. Add `OPENAI_API_KEY` as a server-side environment variable after deploying.

IMPORTANT: Never put an AI API key in `script.js` or `index.html`.
